# CareerSync — Job Portal Platform

CareerSync is a Django-based job portal that connects job seekers and employers through job listings, application management, recruitment workflows, and online assessments.

## 🚀 Features & Modules

- **Guest Module:** Browse job listings and explore opportunities.
- **User Module:** Manage profiles, search for jobs, and apply for positions.
- **Job Provider Module:** Manage job postings and review applications.
- **Online Assessment Module:** Conduct MCQ-based examinations to evaluate candidates.
- **Employer Verification Module:** Support employer verification workflows.
- **Admin Module:** Manage users, job providers, and platform activities.
- **Complaints & Feedback Module:** Submit and manage complaints and feedback.

## 🛠️ Tech Stack

- **Backend:** Python, Django
- **Frontend:** HTML5, CSS3, JavaScript
- **Database:** SQLite
- **Asynchronous Requests:** AJAX
- **Templating:** Django Template Engine

## 🔌 API Integrations

- **Google Maps API:** Integrates Google Maps functionality into the application.
- **Email/SMTP:** Supports email communication and notifications, depending on configuration.

## ⚙️ Installation

```bash
git clone https://github.com/vishnuradhakrishnan595-cloud/CareerSync.git
cd CareerSync
cd "Main Project"
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
